### About Me

I'm mainly working on two things:

1. **zen-coding** ([github.com/zen-tradings/zen-coding](https://github.com/zen-tradings/zen-coding))  
   Building a **verified, best-fit coding agent for quantitative research and development**.  
   Built on top of pi, it adds research connectors (arXiv / SSRN / alphaXiv), guardrails, auditable telemetry (Langfuse), an eval harness, and process tracking — so quant research and code development are safer, reproducible, and verifiable.

2. **Internal research**: Building and validating medium-to-low frequency trading strategies.

> Research built to be verified.  
> Agent cost next to strategy return.

Previously: FedML · Alibaba Cloud PAI · Tencent CV Lab  
Education: CMU MSIT · Queen Mary University of London & BUPT
